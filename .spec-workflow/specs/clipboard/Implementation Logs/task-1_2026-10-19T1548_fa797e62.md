## Artifacts

### Functions

#### encode_shapes
- **Purpose:** Native clipboard payload: {format: presstoshape-shapes, version: CURRENT_VERSION, shapes: [encode_shape...]} as UTF-8 JSON bytes
- **Location:** presstoshape/formats/clipboard.py
- **Signature:** (shapes: Sequence[Shape]) -> bytes
- **Exported:** Yes

#### decode_shapes
- **Purpose:** Decode native clipboard payload; shapes bottom to top with stored ids (callers renumber). Raises ClipboardError on oversize (MAX_BYTES), bad JSON, NaN/Infinity, wrong format marker, other version, empty list, any shape decode error
- **Location:** presstoshape/formats/clipboard.py
- **Signature:** (data: bytes) -> list[Shape]
- **Exported:** Yes

#### write_shapes_svg
- **Purpose:** Standalone SVG of shapes without layer groups; viewBox = bounds in doc coordinates so shapes keep their coordinates
- **Location:** presstoshape/formats/svg.py
- **Signature:** (shapes: Sequence[Shape], bounds: Rect) -> str
- **Exported:** Yes

#### read_shapes_svg
- **Purpose:** Shapes of every layer (hidden too) in document order, in the SVG's user space (viewBox origin NOT shifted to 0,0), plus reader notes. Use for clipboard paste instead of read_svg_with_notes
- **Location:** presstoshape/formats/svg.py
- **Signature:** (text: str) -> tuple[list[Shape], list[str]]
- **Exported:** Yes

#### _read_layers / _parse_root / _serialize
- **Purpose:** Internal helpers shared by read_svg_with_notes/read_shapes_svg and write_svg/write_shapes_svg
- **Location:** presstoshape/formats/svg.py
- **Signature:** _read_layers(root, base_matrix) -> (Document, notes); _parse_root(text) -> Element; _serialize(root) -> str
- **Exported:** No

### Classes

#### Integration
