# Implementation Log: Task 8

**Summary:** SVG: a Composite is written as its result <path> (Composite style) with <metadata><presstoshape:composite> holding the parts (nested Composites recursively), each with presstoshape:mode. Reader turns such a path back into a Composite when the parts' result matches the stored d (XOR area under 0.1% of the result area, floor 0.05); on mismatch or an unreadable definition it keeps the plain path and adds a note. read_svg_with_notes returns the notes; open_file appends them to the status message. booleans gains area/mismatch_area. Verified: Inkscape renders the result with the definition invisible, and an Inkscape re-save still opens as a Composite.
